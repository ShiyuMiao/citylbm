# LCZ 在本模型尺度下的有效性讨论

evidence_type: newly_run + preexisting_artifact

状态更新：本文主线结论已不再采用 LCZ 或 LCZ-like 分类，而改用更基础、可迁移的建筑形态参数。本文档仅作为 LCZ 尺度适用性审计材料保留。

LCZ 框架在本研究中具有解释价值，但其适用性必须受到尺度约束。Stewart 和 Oke 提出的 LCZ 原本用于标准化描述城市气候观测场地，强调建筑高度、建筑/树木密度、地表覆盖和人为活动等综合属性；WUDAPT 也将 LCZ 作为面向气候、天气、环境和规划模型的城市形态数据层。因此，LCZ 的基本思想适合用于连接建筑形态与环境性能，但它通常面向局地城市斑块，而不是单个建筑构件或被 CFD 裁切后的校园局部边界。

在 TUM2TWIN 核心模型中，LCZ 的有效性主要体现在形态语义层面。模型能够提供建筑高度、局部建成比例、围合程度、紧凑/开敞关系和近地通道连通性等信息，这些变量与 LCZ 的结构属性相吻合。因此，本文可以使用 `LCZ-like morphology` 来组织不同建筑形态的风环境响应，例如 compact midrise-like、open midrise-like 或 compact highrise-like。这样做的价值在于，它把单纯的几何描述转化为可迁移的城市气候形态语言，使结果不再只停留在某一栋建筑或某一张风速图上。

但本模型不能被解释为官方 LCZ 分类。首先，本文的分析单元是剔除边缘不完整建筑后的中心建筑组件及其 0-20 m、20-50 m 周边开放单元，而不是完整城市斑块。其次，低/中/高围合度是基于本校园核心区内部三分位数得到的相对分类，不是 WUDAPT 或 Stewart-Oke 参数表中的外部阈值。再次，当前模型主要服务风环境模拟，尚未纳入完整地表覆盖、植被冠层、反照率、热储存、人为热和地表湿度等 LCZ 热环境要素。因此，本文不应写作“该区域属于 LCZ2”或“完成了 TUM 校园 LCZ 制图”，而应写作“该区域呈现 compact/open midrise-like 等 LCZ-like 形态特征”。

从数值结果看，LCZ-like 分类在 0-20 m 贴建筑带中的区分力有限，因为所有类型都受到建筑界面强遮蔽影响，VR 普遍极低；在 20-50 m 局地环境带中，LCZ-like 分类更有解释力，因为该尺度开始反映建筑群的围合度、开敞性和高度组合对外部来流恢复的影响。因此，本研究中 LCZ 的有效尺度不是单个立面，而是建筑周边的局地形态上下文。这个结论本身也说明，数字孪生风环境研究应把 LCZ 当作“形态分组与结果解释工具”，而不是把它直接等同为 CFD 输入边界或官方城市气候区图斑。
