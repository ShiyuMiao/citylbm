# 建筑形态阶段转化结论段落

evidence_type: newly_run + blocked

进一步的建筑形态阶段转化分析表明，本实验中的形态效应并不适合被简化为单一建筑高度、占地面积或孔隙率对风速的线性影响。在 101 个保留建筑构件中，0-20 m 近立面带的平均风速比仅为 `0.003182`，而 20-50 m 局地环境带的平均风速比为 `0.005560`，二者之间的平均恢复量为 `0.002378`。这说明近立面区域首先表现为由街区围合和建筑遮蔽共同造成的低速饱和带；真正能够区分不同建筑形式风环境表现的，是建筑外侧 20-50 m 局地环境中是否出现风速恢复和方向性响应。顶部分位恢复组与底部分位恢复组的对比显示，`height_to_sqrt_area` 在高恢复组中更低，Cliff's delta 为 `-0.577`，最佳样本内组合规则为 `mean_height_m_tertile=low + elongation_ratio_tertile=high + relative_enclosure_score_tertile=high`，其平均恢复量为 `0.006537`，高恢复构件占比为 `1.000`。因此，本实验能够在传统街谷遮蔽和局部加速认识之外补充一个更适合数字孪生设计筛查的认识：校园核心区行人层通风改善并不取决于单一开口面积或单体高度，而取决于相对竖向尺度、平面连续性、局地围合度与主导风向入口之间是否形成有效的动量交换路径。该结论只应表述为 FluidX3D 数字孪生样本内的筛查性发现，不能写成实测验证的因果设计准则或通用规范阈值。
