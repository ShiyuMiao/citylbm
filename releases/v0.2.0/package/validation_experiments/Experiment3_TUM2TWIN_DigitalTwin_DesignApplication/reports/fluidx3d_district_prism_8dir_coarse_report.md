# FluidX3D District Prism 8-Direction Coarse Report

evidence_type: newly_run

## Correction

The earlier LoD2 runs covered only the available 27 semantic building files and visually read as a limited campus-core subset. Following the user's correction, the main experiment geometry has been expanded to a whole-block collision model reconstructed from the official merged LoD3 OBJ (`TUM_CentralCampus.obj`).

The raw merged LoD3 OBJ was also tested directly, but its sheet-like triangulation produced unsuitable voxelization artifacts. Therefore, the current main CFD candidate is the closed `district_prism_collision_z0.stl`, generated by rasterizing high building surfaces and extruding them into closed height prisms.

## Evidence Boundary

This is now a whole-block simulation, but it remains a coarse audit layer. It should not yet be reported as final pedestrian-level comfort evidence because dx = 6 m cannot resolve 1.5-2.0 m pedestrian height and the result is not time-averaged. The next grid-sensitivity step has been completed as the district-prism `dx=4 m` 8-direction matrix; further rigor requires time averaging and a higher-resolution local pedestrian subdomain if comfort/safety classification is required.
