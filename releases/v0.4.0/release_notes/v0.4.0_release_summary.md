# CityLBM v0.4.0 Release Summary

Release date: 2026-08-26

## Scope

CityLBM v0.4.0 packages the current Rhino 7 / Grasshopper validation branch and stops further accuracy optimization in this release line. The package is intended for GitHub distribution, workflow inspection, and continued validation development.

This release preserves the current validation scripts, source changes, and diagnostic evidence. It does not claim that AIJ Case A or Case E has reached publication-grade numerical accuracy.

## User Installation Boundary

Users can install `CityLBM.gha` in Grasshopper and generate FluidX3D case files directly.

Real simulation execution still requires a local FluidX3D source tree or executable environment configured in `Run Simulation`. v0.4.0 does not bundle a verified FluidX3D solver binary.
