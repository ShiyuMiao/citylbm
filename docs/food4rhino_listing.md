# CityLBM v0.2.1 — Food4Rhino Listing Draft

## Title
CityLBM — GPU-Accelerated Urban Wind Simulation for Grasshopper

## Short Description (max 256 chars)
One-click GPU LBM wind simulation in Grasshopper. 20 pre-wired components for urban
aerodynamics. Bundled FluidX3D solver — no C++ setup needed. AIJ Case A validation included.

## Long Description

### What is CityLBM?
CityLBM is a Grasshopper plugin that brings GPU-accelerated Computational Fluid Dynamics
(CFD) to architectural design workflows. Powered by FluidX3D (Lattice Boltzmann Method),
it enables urban wind environment simulation directly within Rhino/Grasshopper with
zero external dependencies.

### Key Features
- **20 Components** organized in 3 tabs: Scene, Simulation, Results
- **One-Click AIJ Validation**: Open the included `AIJ_CaseA_OneClick.gh`,
  hit Run, and get wind tunnel comparison against AIJ CFD Guidebook benchmarks
- **Bundled Solver**: FluidX3D.exe pre-compiled — no C++, CUDA, or compiler installation
- **GPU Acceleration**: Hardware-accelerated LBM solving via FluidX3D
- **Full VTK Pipeline**: Read/write/visualize VTK Legacy ASCII from FluidX3D
- **Wind Comfort**: Lawson criteria assessment (sitting/standing/walking)
- **Visualization**: Streamlines, isosurfaces, vector fields, cloud maps,
  vertical slices, wind speed grids, probe points
- **Domain Tools**: Automatic domain generation, building wrapping,
  domain designer with AIJ-compliant sizing

### What's New in v0.2.1
- AIJ Case A one-click validation experiment (`create_casea_gh.bat`)
- 5 new/updated icons (blue IconPark style, 200x200)
- FluidX3D embedded in .gha (no manual install)
- Tab naming: `1 | Scene`, `2 | Simulation`, `3 | Results`

### System Requirements
- Rhino 7 (Windows)
- Grasshopper
- Windows 10/11
- GPU recommended (CPU fallback via FluidX3D)
- ~500 MB disk for VTK output files

### Installation
1. Download `CityLBM_v0.2.1.zip`
2. Run `install.bat` (or copy `CityLBM.gha` to `%APPDATA%\Grasshopper\Libraries\`)
3. Copy `FluidX3D.exe` to `%APPDATA%\CityLBM\`
4. Restart Rhino + Grasshopper

### Quick Start
1. Open `AIJ_CaseA_OneClick.gh` (generated by `create_casea_gh.bat`)
2. All 20 components are pre-wired
3. Press Run → simulation starts
4. View results in Rhino viewport + comparison report in Panel
