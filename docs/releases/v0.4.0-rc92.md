# CityLBM v0.4.0-rc92

Status: Grasshopper official metric-gate release candidate. This is not a formal `v0.4.0` release.

## Changes

- Added `CityLBM/src/Components/Results/CaseEOfficialMetricGateComponent.cs`.
- The component exports a Panel-ready AIJ Case E official metric gate from inside Grasshopper:
  - official z=2 m MAE/RMSE/bias/R2/Pearson rows
  - release threshold rows
  - individual pass/fail gate checks
  - forbidden claims
- Added source and packaged-GHA gates:
  - `docs/experiments/casee/tools/citylbm_casee_official_metric_gate_component_gate.py`

- Integrated the new gates into the reproducibility suite, artifact index, release asset manifest, paper evidence gate, and software-feedback matrix as SF071-SF072.

## Evidence Boundary

This release candidate adds official metric-verdict and claim-boundary support only. It does not run FluidX3D, create new probe CSVs, update `release_gate.json`, improve the official z=2 m metric, prove Rhino loaded the new GHA, promote diagnostic settings to defaults, or support predictive accuracy, mesh independence, LES improvement, calibration-as-validation, or formal `v0.4.0` claims.
