# CityLBM v0.4.0-rc65

## Scope

This release candidate adds a schema gate for the manual Rhino/Grasshopper
load manifest required before claiming that the new CityLBM GHA was loaded.

## Added

- `docs/experiments/casee/tools/rhino_gha_load_manifest_schema_gate.py`
- `docs/experiments/casee/results/rhino_gha_load_manifest_schema_gate.json`
- `docs/experiments/casee/results/rhino_gha_load_manifest_schema_gate.csv`
- `docs/experiments/casee/results/rhino_gha_load_manifest_schema_gate.md`

## Evidence

The gate validates the manual manifest template and, when present, a real
`rhino_gha_load_manifest.json`. It checks required fields, expected plugin
version, expected GHA SHA256, and listed screenshot/log artifacts. On the
current workstation the schema gate passes, but `manual_manifest_present=false`
and `rhino_loaded_new_gha=false`; the template is not treated as load evidence.

## Boundary

This is manual software-load schema evidence only. It does not create Rhino
evidence, prove Rhino/Grasshopper loaded the plugin, run FluidX3D, change solver
defaults, improve official z=2 m metrics, or permit a formal `v0.4.0` release.
Formal `v0.4.0` remains blocked by the official z=2 m metric gate, missing
Rhino/GHA load evidence, GPU runtime recovery, and unresolved VS C++ Build
Tools blockers.

Current official Case E z=2 m metric remains MAE = 21.111 pp, R2 = -2.006330,
Pearson = 0.115756.
