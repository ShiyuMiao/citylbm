# CityLBM v0.4.0-rc41

## Scope

`v0.4.0-rc41` is an accuracy-diagnostic release candidate for AIJ Case E. It
adds a newly-run C005 dx=2 m 4x1x1 domain-decomposition ablation and fixes
native candidate run IDs so non-default domain decompositions cannot overwrite
baseline generated case directories.

This is not a formal `v0.4.0` release.

## Newly-run Case E candidate

- Case: AIJ Case E
- Condition: `ac`
- Wind direction: `N`
- Formal wind vector convention: `(0, -1, 0)`
- Validation height: official z=2 m
- Probe set: 80 official `RS_caseE.csv` probes
- Formal sampling: `raw_trilinear`
- Candidate: C005 dx=2 m 4x1x1 domain-decomposition ablation
- Steps: 48000
- Spinup: 12000
- Source-compile path: audited MinGW/g++ fallback
- Candidate CSV:
  `docs/experiments/casee/results/casee_c005_dx2_decomp4x1x1_20260809_215600_probe_time_mean.csv`

## Claim boundary

This release candidate supports a runtime/decomposition sensitivity claim and a
run-id traceability fix. It does not support predictive accuracy, mesh
independence, LES improvement, a default-parameter promotion, or a formal
`v0.4.0` tag.
