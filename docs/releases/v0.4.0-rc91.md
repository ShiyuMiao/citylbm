Status: Grasshopper remediation-plan release candidate. This is not a formal `v0.4.0` release.

## Changes

- Added `CityLBM/src/Components/Results/CaseERemediationPlanComponent.cs`.
- The component exports a Panel-ready AIJ Case E remediation plan from inside Grasshopper:
  - current release blockers
  - required actions
  - verification commands or artifacts
