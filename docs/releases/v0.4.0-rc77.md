# CityLBM v0.4.0-rc77

`v0.4.0-rc77` refreshes build-chain evidence and the compiled Grasshopper
artifact after re-running the local build audit with the portable CityLBM
toolchain. It is not a formal `v0.4.0` release.

## Updated Evidence

- Rebuilt `CityLBM/bin/CityLBM.gha` through `CityLBM/build.ps1` using
  `E:\citylbm_buildchain\dotnet\dotnet.exe`.
- Refreshed `docs/experiments/casee/results/build_chain_manifest.*`.
- Confirmed portable .NET SDK, existing FluidX3D binary, and MinGW/g++
  fallback are present.
- Confirmed Visual Studio Build Tools 2022 C++ is still not available in the
  current shell and remains gated by administrator/UAC and system-drive-space
  recovery.
- Confirmed GPU runtime remains blocked by `nvidia-smi` reporting a lost GPU.

## Boundary

This release candidate is build-chain traceability evidence only. It does not
add a new FluidX3D solver run, improve official AIJ Case E z=2 m metrics,
promote any diagnostic setting into a default accuracy model, or permit a
formal `v0.4.0` tag.

Formal `v0.4.0` remains blocked with official z=2 m MAE = 21.111 pp,
R2 = -2.006330, and Pearson = 0.115756.
