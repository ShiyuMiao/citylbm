# CityLBM v0.4.0-rc66

## Scope

This release candidate adds a local orphan candidate CSV audit for native Case E
probe-mean outputs that exist in the workstation but are not release-gate
evidence.

## Added

- `docs/experiments/casee/tools/casee_orphan_candidate_csv_audit.py`
- `docs/experiments/casee/results/casee_orphan_candidate_csv_audit.json`
- `docs/experiments/casee/results/casee_orphan_candidate_csv_audit.csv`
- `docs/experiments/casee/results/casee_orphan_candidate_csv_audit.md`

## Evidence

The audit inventories four local untracked native candidate CSV files by SHA256
and metric summary. The best raw official z=2 m candidate remains negative
(`MAE = 13.786 pp`, `R2 = -0.229845`, `Pearson = 0.314966`) and none of the
candidates has complete run-log provenance. `any_formal_result_allowed=false`.

## Boundary

This is local candidate inventory and protocol-risk evidence only. It does not
commit the raw CSVs, prove completed FluidX3D runs without logs, update
`release_gate.json`, change solver defaults, improve official z=2 m metrics, or
permit a formal `v0.4.0` release. Formal `v0.4.0` remains blocked by the
official z=2 m metric gate, missing Rhino/GHA load evidence, GPU runtime
recovery, and unresolved VS C++ Build Tools blockers.

Current release-gate official Case E z=2 m metric remains MAE = 21.111 pp,
R2 = -2.006330, Pearson = 0.115756.
