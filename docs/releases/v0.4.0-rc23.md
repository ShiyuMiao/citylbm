# CityLBM v0.4.0-rc23

## Status

`v0.4.0-rc23` is an accuracy-diagnostic release candidate for AIJ Case E. Formal `v0.4.0` remains blocked.

Current official z=2 m Case E metric, from the audited `raw_trilinear` 80-probe result:

- MAE: 21.111408125 percentage points
- RMSE: 27.72103208243715 percentage points
- Bias: -16.409216 percentage points
- R2: -2.006330362229977
- Pearson: 0.11575649438573923

These metrics do not support a formal predictive-accuracy claim.

## Evidence Boundary

The new gate verifies that:

- formal Case E validation remains official z=2 m, 80 ac+N probes, and `raw_trilinear` sampling;
- generic CityLBM viscosity uses the standard physical-viscosity mapping unless `nuLBM` is explicitly set;
- `Diagnostic LBM Nu Override`, `Diagnostic Z Origin Offset`, effective-ground shifts, wall/roughness follow-ups, and non-raw probe sampling modes remain experimental switches;
- `z_plus_half` and related diagnostic modes are not accepted as formal official z=2 m substitutes.

## Not Claimed

This release candidate does not claim:

- validated predictive accuracy for AIJ Case E;
- mesh independence;
- LES improvement;
- Rhino/Grasshopper loading of the newly built GHA;
- formal `v0.4.0` readiness.
