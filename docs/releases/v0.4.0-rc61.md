# CityLBM v0.4.0-rc61

## Grasshopper plugin identity component

This release candidate adds an in-Grasshopper identity component to make the
manual Rhino/GHA load evidence step easier to verify.

- `Plugin Identity` appears under `CityLBM / Results`
- it outputs the loaded plugin version and assembly version
- it outputs the loaded GHA path and SHA256
- it outputs a `rhino_gha_load_manifest.json` template populated with the
  observed plugin identity
- it outputs an explicit claim boundary stating that software identity is not
  CFD accuracy evidence
- `citylbm_plugin_identity_component_gate.py` audits the component source and is
  integrated into the reproducibility suite, paper evidence gate, artifact
  index, and software-feedback matrix as SF038

## Boundary

This is a software identity and manual Rhino/GHA evidence enhancement only. It
does not prove Rhino/Grasshopper loaded the plugin in this session, recover GPU
runtime, add a new FluidX3D run, change solver defaults, improve official z=2 m
metrics, or permit a formal `v0.4.0` release.

Formal Case E official z=2 m metrics remain:

- MAE = 21.111 pp
- R2 = -2.006330
- Pearson = 0.115756

Formal `v0.4.0` remains blocked until the official z=2 m metric gate and real
Rhino/Grasshopper new-GHA loading evidence pass.
