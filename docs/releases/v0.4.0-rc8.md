# CityLBM v0.4.0-rc8 Release Notes

Status: accuracy diagnostic release candidate. This is not a formal v0.4.0 release.

## Newly Run Evidence

- Added `origin_z_offset_m` support to the native AIJ Case E generator.
- Generated, compiled, and ran a dx=2 m z-center lattice diagnostic for 48000 steps with spinup 12000.
- Put official z=2 m directly on a lattice-center height while preserving the formal `raw_trilinear` z=2 m metric.
- Extended the voxel/probe audit so it records the vertical origin offset and correctly reports whether z=2 m is lattice-centered.

## Diagnostic Findings

- Formal raw_trilinear official z=2 m: MAE = 21.111 pp, RMSE = 27.721 pp, bias = -16.409 pp, R2 = -2.006330, Pearson = 0.115756.
- Best diagnostic sampling mode: `vertical_valid_above`, MAE = 16.041 pp, R2 = -0.554717, Pearson = 0.336940.
- Low protocol-risk probes in the z-center audit: n = 47, raw MAE = 12.435 pp.
- High protocol-risk probes in the z-center audit: n = 14, raw MAE = 34.589 pp.

## Software Changes

- Native Case E generator now supports a documented vertical origin offset diagnostic.
- Voxel/probe audit output now includes `origin_z_offset_m`.
- Validation reports can include separate z-center lattice diagnostic sections.

## Release Gate

Formal `v0.4.0` remains blocked:

- official z=2 m R2 is still negative;
- MAE remains above the release threshold;
- Rhino/Grasshopper loading of the new GHA is not independently verified.
- after the run, `nvidia-smi` reported the GPU as lost, so additional long FluidX3D runs require GPU/driver recovery before execution.

This rc supports a limitations/protocol-risk argument. It does not support a claim that CityLBM has reached research-grade predictive accuracy for AIJ Case E.
