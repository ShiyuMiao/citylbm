# CityLBM v0.4.0-rc78

`v0.4.0-rc78` adds a post-run official audit handoff for AIJ Case E. It is
not a formal `v0.4.0` release and does not add a new FluidX3D result.

## Added

- `casee_postrun_official_audit_handoff.py`, a fail-closed gate for newly
  completed `casee_probe_time_mean.csv` files.
- Handoff outputs:
  - `casee_postrun_official_audit_handoff.json`
  - `casee_postrun_official_audit_handoff.csv`
  - `casee_postrun_official_audit_handoff.md`
- Checks for required formal columns, 80 official probe rows, numeric values,
  native manifest protocol fields, minimum `steps >= 48000`,
  `spinup >= 12000`, and completed run-log evidence.
- The exact `casee_audit.py --release-target v0.4.0 --predicted ...` command
  that must be executed before any new CSV can affect `release_gate.json`.

## Boundary

This handoff is post-run protocol control only. It does not run FluidX3D, does
not improve official z=2 m metrics, does not promote diagnostic columns, does
not change CityLBM default physics, and does not permit formal `v0.4.0`.

Formal `v0.4.0` remains blocked with official z=2 m MAE = 21.111 pp,
R2 = -2.006330, and Pearson = 0.115756.
