# CityLBM v0.4.0-rc94

Status: Grasshopper official residual-diagnostics release candidate. This is not a formal `v0.4.0` release.

## Changes

- Added `CityLBM/src/Components/Results/CaseEOfficialResidualDiagnosticsComponent.cs`.
- The component summarizes residual structure from a completed official Case E probe CSV:
  - top absolute-residual probes
  - observed-speed group summaries
  - group MAE and bias
  - under-prediction fractions
  - protocol and interpretation risk rows
- Added source and packaged-GHA gates:
  - `docs/experiments/casee/tools/citylbm_casee_official_residual_diagnostics_component_gate.py`
  - `docs/experiments/casee/tools/citylbm_casee_official_residual_diagnostics_binary_gate.py`
- Integrated the new gates into the reproducibility suite, artifact index, release asset manifest, paper evidence gate, and software-feedback matrix as SF075-SF076.

## Evidence Boundary

This release candidate adds plugin-side residual-diagnostics and claim-boundary support only. It does not run FluidX3D, create a new probe CSV, update `release_gate.json`, improve the official z=2 m metric, prove Rhino loaded the new GHA, promote diagnostic settings to defaults, or support predictive accuracy, mesh independence, LES improvement, calibration-as-validation, or formal `v0.4.0` claims.
