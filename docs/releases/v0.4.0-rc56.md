# CityLBM v0.4.0-rc56

## Case E release asset manifest

This release candidate adds a curated GitHub Release asset manifest for the
Case E accuracy-diagnostic package. The manifest records which lightweight
artifacts should be uploaded as release assets and which files should remain
excluded or hash-only.

Included upload classes cover the compiled `CityLBM.gha`, validation reports,
CSV/XLSX summaries, figures, data and environment manifests, claim gates,
publication gates, the reproducibility suite, and manuscript support files.
Raw geometry, VTK output, large logs, and other large/source-data artifacts
remain excluded from the curated upload set or represented by hashes.

The release-asset manifest is integrated into the reproducibility suite, paper
evidence gate, publication-readiness gate, artifact index, and software-feedback
matrix as SF034.

## Boundary

This is a release traceability enhancement only. It does not create a GitHub
Release, install Visual Studio Build Tools C++, recover the lost GPU runtime,
add a new FluidX3D run, change solver defaults, improve official z=2 m metrics,
or permit a formal `v0.4.0` release.

Formal Case E official z=2 m metrics remain:

- MAE = 21.111 pp
- R2 = -2.006330
- Pearson = 0.115756

Formal `v0.4.0` remains blocked until the official z=2 m metric gate and
Rhino/Grasshopper new-GHA loading gate pass.
