# CityLBM v0.4.0-rc69

## Scope

This release candidate adds an operational recovery dashboard for the blocked
AIJ Case E follow-up path.

## Added

- `docs/experiments/casee/tools/casee_operational_recovery_dashboard.py`
- `docs/experiments/casee/results/casee_operational_recovery_dashboard.json`
- `docs/experiments/casee/results/casee_operational_recovery_dashboard.csv`
- `docs/experiments/casee/results/casee_operational_recovery_dashboard.md`

## Evidence

The dashboard aggregates existing gates into an ordered recovery path:
system-drive space, VS C++ install readiness, UAC launch, GPU recovery,
Rhino/GHA load evidence, official follow-up preflight, and the formal metric
gate. It records seven active blockers and keeps
`long_fluidx3d_run_allowed=false`; the long-run blockers are system-drive
space, GPU recovery, and official follow-up preflight.

## Boundary

This is operational recovery and run-scheduling evidence only. It does not free
disk space, install Visual Studio Build Tools, recover GPU runtime, load Rhino,
launch FluidX3D, add CFD output, update `release_gate.json`, change solver
defaults, improve official z=2 m metrics, or permit a formal `v0.4.0` release.

Formal `v0.4.0` remains blocked.

R2 = -2.006330, Pearson = 0.115756.
