# CityLBM v0.4.0-rc83

## Status

This is an accuracy-diagnostic release candidate, not a formal v0.4.0 release.

Formal `v0.4.0` remains blocked because the official AIJ Case E z=2 m gate is still negative: MAE = 21.111 pp, R2 = -2.006330, Pearson = 0.115756.

## Added

- Added `casee_native_codegen_smoke_gate.py` to run short native Case E code-generation checks without FluidX3D.
- The smoke gate covers default settings, AF-k/noSGS inlet diagnostics, voxel-dilation wall diagnostics, and C016 residual-target diagnostics.
- The gate verifies generated `setup.cpp`, `defines.hpp`, `buildings.stl`, `citylbm_native_case_manifest.json`, formal z=2 m raw-trilinear manifest fields, default-promotion blockers, Windows path-length margin, and cleanup of temporary native case directories.
- Integrated the smoke gate into the reproducibility suite, artifact index, release asset manifest, paper evidence gate, and software-feedback matrix as SF059.

## Fixed

- Shortened generated native case directory labels for AF-k full-plane inlet diagnostics from the full mode name to `afkfp`.
- Manifest fields still record the full diagnostic mode names, so provenance remains explicit while Windows path length risk is reduced.

## Boundaries

- This rc does not run FluidX3D.
- This rc does not create probe CSVs, update official z=2 m metrics, or improve R2.
- This rc does not promote inlet, wall, C016 residual-target, no-SGS, or any diagnostic switch to the default precision model.
- This rc does not support predictive-accuracy, mesh-independence, LES-improvement, or formal `v0.4.0` claims.
