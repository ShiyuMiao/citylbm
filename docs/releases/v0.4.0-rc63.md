# CityLBM v0.4.0-rc63

## Scope

This release candidate adds a portable build-chain activation gate for the local
CityLBM/FluidX3D workstation.

## Added

- `docs/experiments/casee/tools/citylbm_portable_toolchain_activate.ps1`
- `docs/experiments/casee/tools/citylbm_portable_toolchain_gate.py`
- `docs/experiments/casee/results/citylbm_portable_toolchain_activation.json`
- `docs/experiments/casee/results/citylbm_portable_toolchain_gate.json`
- `docs/experiments/casee/results/citylbm_portable_toolchain_gate.csv`
- `docs/experiments/casee/results/citylbm_portable_toolchain_gate.md`

## Evidence

The gate verifies that the local portable .NET SDK, existing FluidX3D binary,
and MinGW/g++ fallback can be activated for the current process. It records that
Visual Studio Build Tools C++ and GPU runtime remain separate blockers.

## Boundary

This is build-chain reproducibility evidence only. It does not install Visual
Studio Build Tools, recover the lost GPU runtime, run FluidX3D, change solver
defaults, improve official z=2 m metrics, or permit a formal `v0.4.0` release.
Formal `v0.4.0` remains blocked by the official z=2 m metric gate, missing
Rhino/GHA load evidence, GPU runtime recovery, and unresolved VS C++ Build
Tools blockers.

Current official Case E z=2 m metric remains MAE = 21.111 pp, R2 = -2.006330,
Pearson = 0.115756.
