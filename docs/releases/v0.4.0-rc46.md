# CityLBM v0.4.0-rc46

## Scope

`v0.4.0-rc46` adds completed C013-C015 AIJ Case E no-SGS inlet-turbulence
diagnostic runs and extends the evidence chain from C008-C012 to C008-C015. It is not a formal `v0.4.0` release.

## Newly Run Evidence

C013-C015 used the official Case E ac+N z=2 m raw-trilinear protocol with
dx = 2 m, 48000 steps, spinup = 12000, 80 probes, domain decomposition 4x1x1,
AF-k synthetic full-plane inlet, and SUBGRID disabled.

The best candidate is C014:

- inlet turbulence scale: 2.00
- MAE: 13.7856467875 pp
- RMSE: 17.730306046944502 pp
- Bias: -3.5140317875 pp
- R2: -0.22984501828340775
- Pearson: 0.31496559664177526

C015 scale 2.50 rolled back:

- MAE: 13.9112361625 pp
- R2: -0.2540964291683978
- Pearson: 0.29367767575075826

## Claim Boundary

C014 is the strongest current diagnostic improvement, but R2 remains negative.
The no-SGS/inlet-scale combination is a benchmark diagnostic setting, not a
default accuracy model. This release candidate does not support predictive
accuracy, mesh independence, LES improvement, default-parameter promotion, or a
formal `v0.4.0` tag.
