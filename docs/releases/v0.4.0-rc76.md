# CityLBM v0.4.0-rc76

## Scope

This release candidate adds a workspace hygiene gate for the Case E
accuracy-diagnostic release line.

## Changed

- Added `casee_workspace_hygiene_gate.py`.
- The gate classifies ignored local caches, native candidate CSVs, runtime logs,
  and visualization scratch files so they cannot be mistaken for release or
  paper evidence.
- `.gitignore` now excludes local build caches, native result scratch CSVs,
  solver logs, and ParaView helper scratch scripts.
- The gate fails if unexpected untracked files or tracked heavy/raw artifacts
  appear outside the curated evidence chain.

## Evidence

- Workspace hygiene gate:
  `docs/experiments/casee/results/casee_workspace_hygiene_gate.json`
- Reproducibility suite:
  `docs/experiments/casee/results/casee_reproducibility_suite.json`

## Boundary

This is evidence hygiene only. It does not delete files, run FluidX3D, improve
official z=2 m metrics, create a GitHub Release, or permit formal `v0.4.0`.

Formal `v0.4.0` remains blocked.

Current release-gate official Case E z=2 m metrics remain MAE = 21.111 pp,
R2 = -2.006330, Pearson = 0.115756. Local candidate CSVs without complete run
logs remain limitations-only or blocked evidence.
