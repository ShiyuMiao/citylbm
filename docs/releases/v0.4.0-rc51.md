# CityLBM v0.4.0-rc51

## Case E manuscript claim-support gate

This release candidate adds a paper-facing claim-support gate for AIJ Case E.
It converts the manuscript claim matrix into a machine-checkable triage table:

- methods/protocol claims that can be used in the validation protocol section;
- the official z=2 m negative validation result that belongs in Results and
  Limitations;
- diagnostic improvements that are limitations-only and cannot replace the
  formal raw-trilinear protocol;
- reproducibility/build-chain context;
- blocked formal-release claims.

New artifacts:

- `docs/experiments/casee/tools/casee_claim_support_gate.py`
- `docs/experiments/casee/results/casee_claim_support_gate.json`
- `docs/experiments/casee/results/casee_claim_support_gate.csv`
- `docs/experiments/casee/results/casee_claim_support_gate.md`

The gate is integrated into the reproducibility suite, paper evidence gate,
artifact index, paper results packet, and software-feedback matrix as SF030.

## Boundary

This is a claim-control and manuscript-readiness enhancement only. It does not
add a new FluidX3D run, change CityLBM solver defaults, improve official
z=2 m metrics, or permit a formal `v0.4.0` release.

Formal Case E official z=2 m metrics remain:

- MAE = 21.111 pp
- R2 = -2.006330
- Pearson = 0.115756

C014 remains the strongest diagnostic candidate only:

- MAE = 13.786 pp
- R2 = -0.229845
- Pearson = 0.314966

Formal `v0.4.0` remains blocked until the official z=2 m metric gate and
Rhino/Grasshopper new-GHA loading gate pass.
