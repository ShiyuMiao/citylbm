# CityLBM v0.4.0-rc50

## Scope

`v0.4.0-rc50` adds a Case E solver-run provenance ledger for manuscript and
appendix use. It consolidates existing evidence; it is not a formal `v0.4.0`
accuracy release and does not add a new FluidX3D run.

## Newly Run Evidence

The new ledger script generates:

- `casee_solver_run_provenance_ledger.json`
- `casee_solver_run_provenance_ledger.csv`
- `casee_solver_run_provenance_ledger.md`

The ledger maps official-height Case E results to:

- command/config provenance;
- case manifest path;
- probe CSV path and SHA256;
- FluidX3D run log path and SHA256;
- metric values;
- evidence type;
- solver-output evidence type;
- paper-use boundary and limitations.
