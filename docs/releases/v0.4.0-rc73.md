# CityLBM v0.4.0-rc73

## Scope

This release candidate hardens the CityLBM Grasshopper plugin build path so the
packaged `CityLBM.gha` is byte-stable across repeated Release builds on the
current machine.

## Changed

- Enabled deterministic C# compilation metadata in `CityLBM/CityLBM.csproj`.
- Fixed the plugin assembly/file/informational version metadata for the
  `0.4.0-rc` line.
- Removed ILRepack parallel merging from the packaged GHA path and pinned the
  merged assembly version to `0.4.0.0`.
- Added `citylbm_build_hash_stability_gate.py`, which runs two Release builds,
  compares the tracked/release/nested GHA SHA256 values, and restages the final
  tracked GHA into Grasshopper Libraries.

## Boundary

This is software-build reproducibility and packaging evidence only. It does not
prove Rhino/Grasshopper loaded the plugin in a running session, run FluidX3D,
improve official z=2 m metrics, or permit formal `v0.4.0`.

Formal `v0.4.0` remains blocked.
