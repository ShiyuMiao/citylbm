# CityLBM v0.4.0-rc37

## Scope

`v0.4.0-rc37` is an accuracy-diagnostic and reproducibility release candidate
for AIJ Case E. It adds a newly-run rerun of the currently compiled z-center
FluidX3D setup and tightens the build-chain/candidate-sweep gates.

This is not a formal `v0.4.0` release.

## Newly-run Case E rerun

- Case: AIJ Case E
- Condition: `ac`
- Wind direction: `N`
- Formal wind vector convention: `(0, -1, 0)`
- Validation height: official z=2 m
- Probe set: 80 official `RS_caseE.csv` probes
- Formal sampling: `raw_trilinear`
- Rerun command boundary: current compiled binary under
  `E:/citylbm_buildchain/FluidX3D`
- Rerun log:
  `docs/experiments/casee/results/fluidx3d_dx2_zcenter_rerun_20260809_203439.log`
- Rerun CSV:
  `docs/experiments/casee/results/casee_native_dx2_zcenter_rerun_20260809_203439_probe_time_mean.csv`

The rerun completed 48000 steps and reproduced the baseline official z=2 m CSV
and metrics exactly:

- MAE: 21.111408125 pp
- RMSE: 27.72103208243715 pp
- Bias: -16.409216 pp
- R2: -2.006330362229977
- Pearson: 0.11575649438573923

## Software and evidence updates

- Added `casee_zcenter_rerun_consistency.py`.
- Added `casee_zcenter_rerun_consistency.json`, `.csv`, and `.md`.
- Added MinGW/g++ fallback detection to `build_chain_audit.py`.
- Tightened the official run preflight so new generated native candidates
  require an audited source-compile path.
- Tightened the candidate sweep plan so current compiled-binary reruns are not
  conflated with source-recompiled new candidates.
- Integrated the rerun audit into the reproducibility suite, artifact index,
  paper evidence gate, reproducibility appendix, paper results packet, and
  software-feedback matrix.

## Claim boundary

This release candidate supports reproducibility and limitations claims only. It
does not improve the official z=2 m metric, does not support predictive
accuracy, does not prove mesh independence or LES improvement, and does not
allow a formal `v0.4.0` tag.
