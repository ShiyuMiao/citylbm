# CityLBM v0.4.0-rc60

## Rhino load evidence kit

This release candidate adds a fail-closed evidence collection kit for the
remaining Rhino/Grasshopper new-GHA load gate.

- `casee_rhino_load_evidence_kit.py` detects local Rhino executables
- it checks the staged `CityLBM.gha` against the tracked release asset SHA256
- it writes JSON/CSV/Markdown audit outputs
- it generates `rhino_gha_load_manifest.template.json` for the later manual
  Rhino/Grasshopper session check
- it is integrated into the reproducibility suite, paper evidence gate,
  artifact index, and software-feedback matrix as SF037

The kit deliberately does not create
`docs/experiments/casee/results/rhino_gha_load_manifest.json`. That file must
come from a real Rhino/Grasshopper session with screenshot/log evidence before
`rhino_gha_load_gate.py` may pass.

## Boundary

This is a manual software-load evidence collection enhancement only. It does
not prove Rhino/Grasshopper loaded the plugin, recover GPU runtime, add a new
FluidX3D run, change solver defaults, improve official z=2 m metrics, or
permit a formal `v0.4.0` release.

Formal Case E official z=2 m metrics remain:

- MAE = 21.111 pp
- R2 = -2.006330
- Pearson = 0.115756

Formal `v0.4.0` remains blocked until the official z=2 m metric gate and real
Rhino/Grasshopper new-GHA loading evidence pass.
