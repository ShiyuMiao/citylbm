# CityLBM v0.4.0-rc49

## Scope

`v0.4.0-rc49` adds a C016 residual-target calibration-leakage guard for AIJ
Case E. It is a protocol-risk and software-feedback release candidate, not a
formal `v0.4.0` accuracy release.

## Newly Run Evidence

The new guard script generates:

- `casee_c016_residual_target_leakage_guard.json`
- `casee_c016_residual_target_leakage_guard.csv`
- `casee_c016_residual_target_leakage_guard.md`

The guard allows C014 residuals to motivate pre-registered C016 physics
hypotheses, but blocks:

- fitting residual corrections on the same 80 official `RS_caseE` probes and
  reporting them as validation;
- treating post-hoc affine calibration as official z = 2 m evidence;
- promoting `residT` / `residS`, no-SGS, or inlet-scale settings as defaults
  before the external release gate passes.
