# CityLBM v0.4.0-rc79

## Status

This is an accuracy-diagnostic release candidate, not a formal v0.4.0 release.

Formal `v0.4.0` remains blocked because the official AIJ Case E z=2 m gate is still negative: MAE = 21.111 pp, R2 = -2.006330, Pearson = 0.115756.

## Added

- Added the Grasshopper `Case E Post-run Audit` component under `CityLBM > Results`.
- The component checks whether a completed Case E candidate CSV is structurally ready for the official z=2 m `raw_trilinear` audit path.
- The component outputs the required `casee_audit.py --release-target v0.4.0 --predicted <csv>` command, a claim-readiness state, a SHA256 digest, and a protocol report.
- Added source and packaged-GHA gates:
  - `citylbm_casee_postrun_audit_component_gate.py`
  - `citylbm_casee_postrun_audit_binary_gate.py`

## Evidence Chain

- Integrated the new component gates into the reproducibility suite, artifact index, paper evidence gate, release asset manifest, and software feedback matrix as SF055.
- The gate is intentionally fail-closed: it does not compute R2 inside Grasshopper and does not allow formal accuracy claims.

## Boundaries

- This rc does not run FluidX3D.
- This rc does not update official z=2 m metrics.
- This rc does not promote any diagnostic setting to the default precision model.
- This rc does not support predictive-accuracy, mesh-independence, LES-improvement, or formal `v0.4.0` claims.
