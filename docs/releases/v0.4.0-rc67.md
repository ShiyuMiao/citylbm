# CityLBM v0.4.0-rc67

## Scope

This release candidate adds a default-audit elevated launcher gate for the
Visual Studio Build Tools 2022 C++ recovery path.

## Evidence

The gate passed in audit mode and did not launch installation. It verifies that
the launcher delegates to the existing VS C++ recovery script, uses explicit
`-Launch` for UAC elevation, records the post-install verifier, and keeps claim
boundaries closed. The current machine reports
`can_launch_elevated_install_now=false` because C: free space is below 8 GB.

## Boundary

This is build-chain recovery traceability only. It does not install Visual
Studio Build Tools during the suite, recover GPU runtime, launch FluidX3D, add
CFD output, update `release_gate.json`, change solver defaults, improve
official z=2 m metrics, or permit a formal `v0.4.0` release.

Formal `v0.4.0` remains blocked.
