# CityLBM v0.4.0-rc39

## Scope

`v0.4.0-rc39` is an accuracy-diagnostic release candidate for AIJ Case E. It
adds a newly-run C003 z-origin ablation and integrates the result into the
software-feedback and paper-evidence gates.

This is not a formal `v0.4.0` release.

## Newly-run Case E candidate

- Case: AIJ Case E
- Condition: `ac`
- Wind direction: `N`
- Formal wind vector convention: `(0, -1, 0)`
- Validation height: official z=2 m
- Probe set: 80 official `RS_caseE.csv` probes
- Formal sampling: `raw_trilinear`
- Candidate: C003 dx=2 m no-z-center ablation
- Steps: 48000
- Spinup: 12000
- Source-compile path: audited MinGW/g++ fallback
- Candidate CSV:
  `docs/experiments/casee/results/casee_c003_dx2_no_zcenter_20260809_212601_probe_time_mean.csv`
- Run log:
  `docs/experiments/casee/results/fluidx3d_c003_dx2_no_zcenter_run_20260809_212601.log`
- Audit:
  `docs/experiments/casee/results/casee_c003_zorigin_ablation_audit.json`

The C003 run completed 48000 steps and wrote the required official 80-probe
z=2 m CSV. It did not improve the formal metric relative to the current
z-center baseline:

- MAE: 23.125594087499998 pp
- RMSE: 28.695377268333043 pp
- Bias: -20.765241212499998 pp
- R2: -2.221378753276796
- Pearson: 0.09921683588947784
- Delta MAE vs z-center baseline: +2.0141859624999974 pp
- Delta R2 vs z-center baseline: -0.21504839104681928
- Delta Pearson vs z-center baseline: -0.016539658496261392

The run is consistent with the preexisting no-z-center artifact within the
audit tolerance. The current best formal official z=2 m result remains the
z-center baseline: MAE 21.111408125 pp, R2 -2.006330362229977, and Pearson
0.11575649438573923.

## Claim boundary

This release candidate supports a limitations claim: z-origin placement affects
the official z=2 m near-wall/probe-protocol metric, but the diagnostic alignment
is not a validated default accuracy model. It does not support predictive
accuracy, mesh independence, LES improvement, a default-parameter promotion, or
a formal `v0.4.0` tag.
