## Paper Evidence Status

The paper evidence gate passes because the manuscript-facing materials stay within the current evidence boundary:

- protocol and build/workflow claims are paper-ready;
- official z=2 m accuracy is a negative validation result;
- z-center and probe-mode improvements are diagnostic only;
- near-wall, voxelization, wall-model, and probe-protocol issues belong in limitations;
- formal predictive-accuracy, LES-improvement, and mesh-independence claims remain blocked.

## Release Gate

Formal `v0.4.0` remains blocked:

- official z=2 m R2 is negative;
- MAE remains above the release threshold;
- Rhino/Grasshopper loading of the newly built GHA is not independently verified;
- VS Build Tools C++ and GPU runtime remain blockers for additional native validation.
