# CityLBM v0.4.0-rc81

## Status

This is an accuracy-diagnostic release candidate, not a formal v0.4.0 release.

Formal `v0.4.0` remains blocked because the official AIJ Case E z=2 m gate is still negative: MAE = 21.111 pp, R2 = -2.006330, Pearson = 0.115756.

## Added

- Added `casee_inlet_followup_codegen_gate.py` to verify the default-off native AF_caseE-k full-plane inlet follow-up path remains manifest-traced and blocked from default accuracy promotion.
- Integrated the inlet follow-up gate into the reproducibility suite, artifact index, release asset manifest, paper evidence gate, and software-feedback matrix as SF057.

## Experiment Planning

- Replaced the R007 inlet-turbulence TODO with a concrete native Case E generation command using the current best diagnostic no-SGS AF-k inlet setting:
  - `--inlet-turbulence-mode k_synthetic_fullplane`
  - `--inlet-turbulence-scale 2.00`
  - `--no-subgrid`
- Updated the candidate sweep so C008-C015 is treated as default-off inlet follow-up codegen rather than a missing-implementation placeholder.

## Boundaries

- This rc does not run FluidX3D.
- This rc does not update official z=2 m metrics.
- This rc does not promote AF-k synthetic inlet turbulence, no-SGS settings, wall options, or any diagnostic switch to the default precision model.
- This rc does not support predictive-accuracy, mesh-independence, LES-improvement, or formal `v0.4.0` claims.
