# CityLBM v0.4.0-rc85

## Status

This is an accuracy-diagnostic release candidate, not a formal v0.4.0 release.

Formal `v0.4.0` remains blocked because the official AIJ Case E z=2 m gate is still negative: MAE = 21.111 pp, R2 = -2.006330, Pearson = 0.115756.

## Added

- Added `casee_default_promotion_gate.py` to convert Case E default-promotion requirements into per-setting blockers.
- The gate covers `nuLBM`, `zOff`, wall model, roughness length, inlet turbulence, residual target, and diagnostic probe-sampling modes.
- The gate requires official z=2 m raw-trilinear metric success, Case A smoke regression, Rhino/GHA load evidence, no z-plus substitution, no RS_caseE target fitting, and traceable command/log/CSV/figure evidence before any diagnostic can become a default precision model.
- Integrated the gate into the reproducibility suite, artifact index, release asset manifest, paper evidence gate, and software-feedback matrix as SF061.

## Boundaries

- This rc does not run FluidX3D.
- This rc does not create probe CSVs, update official z=2 m metrics, or improve R2.
- This rc explicitly blocks diagnostic default promotion under the current negative official metrics.
- This rc does not support predictive-accuracy, mesh-independence, LES-improvement, or formal `v0.4.0` claims.
