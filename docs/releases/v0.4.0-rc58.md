# CityLBM v0.4.0-rc58

## GHA staging/install audit

This release candidate adds an audit-only check for whether the tracked
`CityLBM/bin/CityLBM.gha` is staged for Grasshopper loading. The new
`citylbm_gha_install_audit.py` script:

- computes the tracked GHA SHA256 and compares it with the plugin identity gate
- scans common Grasshopper Libraries directories for `CityLBM*.gha`
- reports whether an installed/staged GHA already matches the tracked build
- records a manual PowerShell copy command for staging the current GHA
- keeps the Rhino/Grasshopper load gate fail-closed until real Rhino session
  evidence exists

The audit is integrated into the reproducibility suite, paper evidence gate,
publication-readiness gate, artifact index, release asset manifest, and
software-feedback matrix as SF036.

## Boundary

This is a software-delivery traceability enhancement only. It does not copy
files automatically, prove Rhino/Grasshopper loaded the plugin, recover GPU
runtime, add a new FluidX3D run, change solver defaults, improve official z=2 m
metrics, or permit a formal `v0.4.0` release.

Formal Case E official z=2 m metrics remain:

- MAE = 21.111 pp
- R2 = -2.006330
- Pearson = 0.115756

Formal `v0.4.0` remains blocked until the official z=2 m metric gate and real
Rhino/Grasshopper new-GHA loading evidence pass.
