# CityLBM v0.4.0-rc84

## Status

This is an accuracy-diagnostic release candidate, not a formal v0.4.0 release.

Formal `v0.4.0` remains blocked because the official AIJ Case E z=2 m gate is still negative: MAE = 21.111 pp, R2 = -2.006330, Pearson = 0.115756.

## Added

- Added `casee_runbook_codegen_preflight.py` to preflight the next-run official follow-up commands before GPU scheduling.
- The gate executes only the `generate_native_casee.py` step for R005, R006, R007, R008, and R010.
- The gate verifies generated native case files, official z=2 m raw-trilinear manifest fields, diagnostic default-promotion blockers, Windows path-length margin, absence of solver CSV output, and cleanup of temporary native case directories.
- Integrated the preflight into the reproducibility suite, artifact index, release asset manifest, paper evidence gate, and software-feedback matrix as SF060.

## Boundaries

- This rc does not deploy generated cases to FluidX3D.
- This rc does not run FluidX3D, create probe CSVs, update official z=2 m metrics, or improve R2.
- This rc does not promote inlet, wall, C016 residual-target, no-SGS, dx=1, or any diagnostic switch to the default precision model.
- This rc does not support predictive-accuracy, mesh-independence, LES-improvement, or formal `v0.4.0` claims.
