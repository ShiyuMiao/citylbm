# CityLBM v0.4.0-rc70

## Scope

This release candidate improves CityLBM plugin build quality and null-safety
without changing Case E physics defaults or official validation metrics.

## Changed

- Removed nullable-build warnings from the CityLBM Release rebuild path.
- Added explicit default values to FluidX3D result DTOs and VTK result buffers.
- Made FluidX3D executable/MSBuild/g++ discovery paths explicitly nullable.
- Hardened ASCII and binary VTK readers around structured-grid origin,
  spacing, scalar-name, and latest-output lookup fallbacks.
- Kept all AIJ Case E diagnostic controls default-off and non-formal.
