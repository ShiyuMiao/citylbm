# CityLBM v0.4.0-rc90

Status: Grasshopper paper claim-card release candidate. This is not a formal `v0.4.0` release.

## Changes

- Added `CityLBM/src/Components/Results/CaseEPaperClaimCardComponent.cs`.
- The component exports a Panel-ready AIJ Case E claim card from inside Grasshopper:
  - paper-ready negative-validation statements
  - limitations statements
  - forbidden claims
  - evidence paths for the current Case E evidence chain
- Added source and packaged-GHA gates:
  - `docs/experiments/casee/tools/citylbm_casee_paper_claim_card_component_gate.py`
  - `docs/experiments/casee/tools/citylbm_casee_paper_claim_card_binary_gate.py`
- Integrated the new gates into the reproducibility suite, artifact index, release asset manifest, paper evidence gate, and software-feedback matrix as SF067-SF068.

## Evidence Boundary

This release candidate adds paper-writing and claim-boundary support only. It does not run FluidX3D, create new probe CSVs, update `release_gate.json`, improve the official z=2 m metric, prove Rhino loaded the new GHA, promote diagnostic settings to defaults, or support predictive accuracy, mesh independence, LES improvement, calibration-as-validation, or formal `v0.4.0` claims.
