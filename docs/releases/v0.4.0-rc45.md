# CityLBM v0.4.0-rc45

## Scope

`v0.4.0-rc45` adds a completed C012 AIJ Case E inlet-turbulence diagnostic
run and extends the evidence chain from C008-C011 to C008-C012. It is not a formal `v0.4.0` release.

## Newly Run Evidence

C012 command:

```powershell
python docs\experiments\casee\tools\generate_native_casee.py --dx 2 --steps 48000 --spinup 12000 --sample-dt 2000 --ground-offset-cells 1 --origin-z-offset-m 1.0 --nu-lbm 0.001 --domain-x 4 --domain-y 1 --domain-z 1 --inlet-turbulence-mode k_synthetic_fullplane --inlet-turbulence-scale 2.0 --fluidx3d-root E:\citylbm_buildchain\FluidX3D --deploy
```

The generated setup was compiled with the documented MinGW/g++ fallback and run
with FluidX3D device arguments `0 1 2` because `nvidia-smi` still reports GPU3
lost.

## Claim Boundary

C012 is newly-run plateau/rollback evidence for the AF-k synthetic full-plane
inlet sweep. It supports the limitation that blind inlet-turbulence scale growth
is not enough to reach paper-grade official z=2 m accuracy. It does not support
predictive accuracy, mesh independence, LES improvement, default-parameter
promotion, or a formal `v0.4.0` tag.
