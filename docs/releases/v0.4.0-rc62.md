# CityLBM v0.4.0-rc62

## Packaged GHA identity-component gate

This release candidate strengthens the Rhino/GHA evidence chain by checking the
packaged plugin artifact, not only the source tree.

- `citylbm_plugin_identity_binary_gate.py` audits `CityLBM/bin/CityLBM.gha`
- it verifies that the tracked GHA hash matches the plugin identity gate
- it confirms the packaged GHA contains the `Plugin Identity` component markers
- checked markers include component name, GHA SHA256 output, manifest-template
  output, GUID, and the accuracy-claim boundary
- the gate is integrated into the reproducibility suite, paper evidence gate,
  artifact index, and software-feedback matrix as SF039

## Boundary

This is packaged-plugin software identity evidence only. It does not prove
Rhino/Grasshopper loaded the plugin, recover GPU runtime, add a new FluidX3D
run, change solver defaults, improve official z=2 m metrics, or permit a
formal `v0.4.0` release.

Formal Case E official z=2 m metrics remain:

- MAE = 21.111 pp
- R2 = -2.006330
- Pearson = 0.115756

Formal `v0.4.0` remains blocked until the official z=2 m metric gate and real
Rhino/Grasshopper new-GHA loading evidence pass.
