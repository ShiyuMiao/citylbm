# CityLBM v0.4.0-rc52

## Case E publication-readiness gate

This release candidate adds a reviewer-facing publication-readiness gate for
the AIJ Case E manuscript package.

New artifacts:

- `docs/experiments/casee/tools/casee_publication_readiness_gate.py`
- `docs/experiments/casee/results/casee_publication_readiness_gate.json`
- `docs/experiments/casee/results/casee_publication_readiness_gate.csv`
- `docs/experiments/casee/results/casee_publication_readiness_gate.md`

The gate audits ten reviewer-facing questions:

- whether the official Case E protocol is explicit;
- what the formal z=2 m result is;
- whether diagnostic improvements are separated from formal validation;
- whether metrics trace to commands, logs, CSV files, and hashes;
- whether paper figures are source-backed and claim-safe;
- whether the reproducibility appendix is generated from current evidence;
- whether software-feedback changes stay default-safe;
- which blockers prevent formal release;
- whether the publication packet is script-reproducible;
- whether release assets are lightweight and traceable.

The gate is integrated into the reproducibility suite, and the artifact index is
rebuilt after it so the new outputs are hash-indexed.

## Boundary

This is a publication-readiness and reviewer-audit enhancement only. It does
not add a new FluidX3D run, change solver defaults, improve official z=2 m
metrics, or permit a formal `v0.4.0` release.

Formal Case E official z=2 m metrics remain:

- MAE = 21.111 pp
- R2 = -2.006330
- Pearson = 0.115756

Formal `v0.4.0` remains blocked until the official z=2 m metric gate and
Rhino/Grasshopper new-GHA loading gate pass.
