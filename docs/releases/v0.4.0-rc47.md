# CityLBM v0.4.0-rc47

## Scope

`v0.4.0-rc47` adds a residual-structure audit for C014, the current best
AIJ Case E official-height diagnostic candidate. It is not a formal `v0.4.0`
release and does not add a new FluidX3D solver run.

## Newly Run Evidence

The new audit reads the preexisting C014 80-probe official z=2 m raw-trilinear
CSV and generates:

- `casee_c014_residual_structure_audit.json`
- `casee_c014_residual_structure_audit.csv`
- `casee_c014_residual_structure_audit.md`
- `casee_c014_residual_structure_audit.png`
- `casee_c014_residual_top_probes.csv`

## Software Feedback

The audit adds SF026 to the software feedback matrix. The finding is that the
best C014 diagnostic still compresses the velocity-ratio range. The next
software target should be a default-off residual-targeted wall/inlet/channel
response candidate that recovers high-speed corridor probes without
overpredicting sheltered low-speed probes.

## Claim Boundary

Formal `v0.4.0` remains blocked.

This release candidate supports limitations and follow-up design only. It does
not support predictive accuracy, post-hoc affine calibration as validation,
mesh independence, LES improvement, no-SGS/default promotion, or a formal
`v0.4.0` tag.
