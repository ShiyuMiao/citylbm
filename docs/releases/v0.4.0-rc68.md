# CityLBM v0.4.0-rc68

## Scope

This release candidate adds a no-delete system-drive space audit for the Visual
Studio Build Tools 2022 C++ recovery path.

## Added

- `docs/experiments/casee/tools/vs_cpp_system_drive_space_gate.py`
- `docs/experiments/casee/results/vs_cpp_system_drive_space_gate.json`
- `docs/experiments/casee/results/vs_cpp_system_drive_space_gate.csv`
- `docs/experiments/casee/results/vs_cpp_system_drive_space_gate.md`

## Evidence

The gate passed in audit mode and did not delete files. It records that C: has
4.986 GB free against the configured 8 GB preflight threshold, leaving a
3.014 GB shortfall. Low-risk cleanup candidates total 0.921 GB, which is not
enough to cover the shortfall. VS C++ recovery therefore remains blocked until
larger manual system-drive cleanup is completed and
`python docs/experiments/casee/tools/vs_cpp_elevated_launcher_gate.py` is rerun.

## Boundary

This is build-chain operational evidence only. It does not delete files, install
Visual Studio Build Tools, recover GPU runtime, launch FluidX3D, add CFD output,
update `release_gate.json`, change solver defaults, improve official z=2 m
metrics, or permit a formal `v0.4.0` release.

Formal `v0.4.0` remains blocked.

Current release-gate official Case E z=2 m metrics remain MAE = 21.111 pp,
R2 = -2.006330, Pearson = 0.115756.
