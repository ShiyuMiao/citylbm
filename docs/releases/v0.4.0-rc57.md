# CityLBM v0.4.0-rc57

## VS C++ Build Tools recovery gate

This release candidate adds a non-destructive recovery path for the Windows
Visual Studio Build Tools 2022 C++ dependency. The new PowerShell script
`vs_cpp_buildtools_recovery.ps1` audits the current machine by default and only
attempts installation when `-Install` is supplied explicitly.

The accompanying `vs_cpp_recovery_gate.py` records:

- whether VS C++ tools are currently discoverable by `vswhere`
- whether `cl.exe`, `msbuild.exe`, and `vcvars64.bat` are available
- whether the shell is elevated
- whether system-drive free space is above the configured threshold
- the exact winget command for manual recovery
- current blockers and claim boundaries

The gate is integrated into the reproducibility suite, paper evidence gate,
publication-readiness gate, artifact index, release asset manifest, and
software-feedback matrix as SF035.

## Boundary

This is a build-chain recovery enhancement only. It does not install Visual
Studio Build Tools by default, recover the lost GPU runtime, add a new FluidX3D
run, change solver defaults, improve official z=2 m metrics, or permit a formal
`v0.4.0` release.

Formal Case E official z=2 m metrics remain:

- MAE = 21.111 pp
- R2 = -2.006330
- Pearson = 0.115756

Formal `v0.4.0` remains blocked until the official z=2 m metric gate,
Rhino/Grasshopper new-GHA loading gate, GPU runtime, and operational build-chain
gates pass.
