# CityLBM v0.4.0-rc55

## Portable plugin build script

This release candidate improves the reproducibility of the CityLBM plugin
build on the new computer. `CityLBM/build.ps1` now supports:

- `-DotNetPath` for an explicit SDK executable
- `CITYLBM_DOTNET` as an environment override
- automatic fallback to `E:\citylbm_buildchain\dotnet\dotnet.exe`
- fallback to `dotnet` on `PATH`
- `-NoPause` for non-interactive CI/suite execution

The build-chain audit now records a `citylbm_build_script` section with the
script hash, portable-SDK support checks, a smoke-build command, return code,
and packaged GHA metadata. The software-feedback matrix records this as SF033.

## Boundary

This is a plugin build-chain reproducibility enhancement only. It does not
install Visual Studio Build Tools C++, recover the lost GPU runtime, add a new
FluidX3D run, change solver defaults, improve official z=2 m metrics, or
permit a formal `v0.4.0` release.

Formal Case E official z=2 m metrics remain:

- MAE = 21.111 pp
- R2 = -2.006330
- Pearson = 0.115756

Formal `v0.4.0` remains blocked until the official z=2 m metric gate and
Rhino/Grasshopper new-GHA loading gate pass.
