# CityLBM v0.4.0-rc75

## Scope

This release candidate adds a GitHub publication gate for the Case E
accuracy-diagnostic release line.

## Changed

- Added `github_release_publication_gate.py`.
- The gate audits the latest completed local rc tag, records the next
  recommended rc tag, and verifies whether the audited tag is visible on
  GitHub.
- The gate checks whether a GitHub Release already exists for the rc tag.
- The gate records whether `gh` CLI is available and authenticated enough to
  create a release from the local machine.
- The gate falls back to `git ls-remote` when the GitHub API returns a
  non-success status for tag visibility.
- `CityLBM/build.ps1` now skips overwriting tracked/nested GHA files when the
  destination already has the same SHA256, avoiding repeated-build failures
  caused by Windows file locks.

## Boundary

This is publication-state evidence only. It does not create a GitHub Release,
run FluidX3D, improve official z=2 m metrics, or permit formal `v0.4.0`.

Formal `v0.4.0` remains blocked.
