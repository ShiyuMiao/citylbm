# CityLBM v0.4.0-rc38

## Scope

`v0.4.0-rc38` is an accuracy-diagnostic release candidate for AIJ Case E. It
adds a newly-run C002 longer time-mean FluidX3D follow-up and integrates the
negative result into the software-feedback and paper-evidence gates.

This is not a formal `v0.4.0` release.

## Newly-run Case E candidate

- Case: AIJ Case E
- Condition: `ac`
- Wind direction: `N`
- Formal wind vector convention: `(0, -1, 0)`
- Validation height: official z=2 m
- Probe set: 80 official `RS_caseE.csv` probes
- Formal sampling: `raw_trilinear`
- Candidate: C002 dx=2 m z-center longer mean
- Steps: 96000
- Spinup: 24000
- Source-compile path: audited MinGW/g++ fallback
- Candidate CSV:
  `docs/experiments/casee/results/casee_c002_dx2_longer_mean_20260809_205343_probe_time_mean.csv`
- Run log:
  `docs/experiments/casee/results/fluidx3d_c002_dx2_longer_mean_run_20260809_205343.log`
- Audit:
  `docs/experiments/casee/results/casee_c002_longer_mean_audit.json`

The C002 run completed 96000 steps and wrote the required official 80-probe
z=2 m CSV. It did not improve the formal metric relative to the current
z-center baseline:

- MAE: 22.015022499999997 pp
- RMSE: 28.53349858273545 pp
- Bias: -17.617840675 pp
- R2: -2.1851358653077058
- Pearson: -0.0089370077112125
- Delta MAE vs baseline: +0.9036143749999977 pp
- Delta R2 vs baseline: -0.17880550307772867
- Delta Pearson vs baseline: -0.12469350209695172

The current best formal official z=2 m result remains the z-center baseline:
MAE 21.111408125 pp, R2 -2.006330362229977, and Pearson
0.11575649438573923.

## Claim boundary

This release candidate supports a negative follow-up claim: extending the
current dx=2 m z-center setup to a longer averaging window did not improve the
official z=2 m Case E result. It does not support predictive accuracy, mesh
independence, LES improvement, a default-parameter promotion, or a formal
`v0.4.0` tag.
