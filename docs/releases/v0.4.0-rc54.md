# CityLBM v0.4.0-rc54

## Run Simulation publication gate output

This release candidate makes the manuscript-use boundary visible inside the
CityLBM Grasshopper plugin. The `Run Simulation` component now exposes a
`Publication Gate` output beside the existing manifest and claim-gate outputs.

For AIJ Case E preset runs, the output states that manuscript use requires:

- `casee_publication_readiness_gate.json`
- `casee_claim_support_gate.json`
- solver-run provenance ledger
- paper figure QA
- the reproducibility suite

Updated gates:

- `citylbm_manifest_output_gate.py`
- `citylbm_software_feedback_matrix.py` as SF032
- `casee_publication_readiness_gate.py`
- `paper_evidence_gate.py`

## Boundary

This is a plugin UI traceability and claim-boundary enhancement only. It does
not add a new FluidX3D run, change solver defaults, improve official z=2 m
metrics, or permit a formal `v0.4.0` release.

- MAE = 21.111 pp
