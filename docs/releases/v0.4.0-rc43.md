# CityLBM v0.4.0-rc43

## Scope

`v0.4.0-rc43` is an accuracy-diagnostic release candidate for AIJ Case E. It
extends the default-off AF-k synthetic full-plane inlet sweep from C008/C009 to
C010/C011 and reports the best completed 48000-step inlet-turbulence candidate.

This is not a formal `v0.4.0` release.

## Newly-run Case E candidates

- Case: AIJ Case E
- Condition: `ac`
- Wind direction: `N`
- Formal wind vector convention: `(0, -1, 0)`
- Validation height: official z=2 m
- Probe set: 80 official `RS_caseE.csv` probes
- Formal sampling: `raw_trilinear`
- Candidates: C008 scale 0.35, C009 scale 0.70, C010 scale 1.00, C011 scale 1.50
- Inlet: default-off `k_synthetic_fullplane` using `AF_caseE.csv` z,U,k
- Steps: 48000
- Spinup: 12000
- Source-compile path: audited MinGW/g++ fallback
- Runtime note: GPU3 was reported lost by `nvidia-smi`; C010/C011 were launched with FluidX3D device arguments `0 1 2`
- Audit:
  `docs/experiments/casee/results/casee_c008_c009_inlet_turbulence_audit.json`

Best candidate C011:

- MAE: 14.3750643375 pp
- RMSE: 18.41596115408416 pp
- Bias: -4.6872345375 pp
- R2: -0.32680378704255153
- Pearson: 0.2856641275815884
- Delta MAE vs z-center baseline: -6.73634375 pp
- Delta R2 vs z-center baseline: +1.679526670176449
- Delta Pearson vs z-center baseline: +0.16990764609679754

## Claim boundary

This release candidate supports a diagnostic improvement claim: AF-k full-plane
inlet turbulence is the strongest current route for reducing official-height
Case E error. It does not support predictive accuracy, mesh independence, LES
improvement, a default-parameter promotion, or a formal `v0.4.0` tag because
R2 remains negative and the inlet scale was explored on the benchmark.
