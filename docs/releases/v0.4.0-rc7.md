# CityLBM v0.4.0-rc7 Release Notes

Status: accuracy diagnostic release candidate. This is not a formal v0.4.0 release.

## Newly Run Evidence

- Added and ran a voxel/probe protocol audit for the official AIJ Case E z=2 m probes.
- Parsed `BD_caseE.stl`, applied scale factor 250, and compared probe locations against the dx=2 m effective-ground grid used by the best diagnostic run.
- Updated CityLBM source so generated Case E run manifests record probe protocol risk metadata.

Evidence:

- `docs/experiments/casee/results/casee_voxel_probe_audit.csv`
- `docs/experiments/casee/results/casee_voxel_probe_audit_groups.csv`

## Diagnostic Findings

- Low protocol-risk probes: n = 25, raw MAE = 12.932 pp.
- Moderate protocol-risk probes: n = 36, raw MAE = 27.162 pp.
- High protocol-risk probes: n = 19, raw MAE = 32.454 pp.
- z_plus_half diagnostic sampling improves all-probe MAE from 23.972 pp to 21.217 pp, but R2 remains negative.
- The official z = 2 m height lies halfway between z = 1 m and z = 3 m lattice centers in the dx = 2 m effective-ground diagnostic.

## Software Changes

- CityLBM `citylbm_run_manifest.json` now includes a `probe_protocol_risk` block for Case E.
- The manifest records formal height, grid z coordinate, lower/upper z lattice centers, and whether the formal height falls between lattice layers.
- The manifest explicitly records that `z_plus_half` is not allowed as a formal substitute for official z = 2 m validation.

## Release Gate

Formal `v0.4.0` remains blocked:

- official z = 2 m R2 is still negative;
- MAE remains above the target;
- Rhino/Grasshopper loading of the new GHA is not independently verified.

This rc supports a limitations/protocol-risk argument and narrows the next optimization target to wall/voxelization treatment.
