# CityLBM v0.4.0-rc93

Status: Grasshopper official CSV metric-calculator release candidate. This is not a formal `v0.4.0` release.

## Changes

- Added `CityLBM/src/Components/Results/CaseEOfficialMetricsFromCsvComponent.cs`.
- The component computes AIJ Case E official z=2 m metrics from a completed probe CSV:
  - `MAE_pp`
  - `RMSE_pp`
  - `bias_pp`
  - `R2`
  - `Pearson`
- The component checks the official protocol boundary:
  - `case=ac`
  - `Wind_direction=N`
  - validation height `z=2 m`
  - 80 official probes
  - `raw_trilinear` sampling
- Added source and packaged-GHA gates:
  - `docs/experiments/casee/tools/citylbm_casee_official_metrics_from_csv_component_gate.py`
  - `docs/experiments/casee/tools/citylbm_casee_official_metrics_from_csv_binary_gate.py`
- Integrated the new gates into the reproducibility suite, artifact index, release asset manifest, paper evidence gate, and software-feedback matrix as SF073-SF074.

## Evidence Boundary

This release candidate adds plugin-side metric recalculation and claim-boundary support only. It does not run FluidX3D, create a new probe CSV, update `release_gate.json`, improve the official z=2 m metric, prove Rhino loaded the new GHA, promote diagnostic settings to defaults, or support predictive accuracy, mesh independence, LES improvement, calibration-as-validation, or formal `v0.4.0` claims.
