# CityLBM v0.4.0-rc5 Release Notes

Status: accuracy diagnostic release candidate. This is not a formal v0.4.0 release.

## Newly Run Evidence

- Spatial alignment diagnostic completed for the best existing official z=2 m run; see `docs/experiments/casee/results/casee_spatial_alignment_diagnostic.csv`.
- Native Case E probe-mode diagnostic runner generated and compiled; see `docs/experiments/casee/results/casee_probe_modes_compile_manifest.json`.

Best official z=2 m accuracy remains unchanged because no new full Case E solver run was completed in this rc:

- Run: `dx2_gshift1_nu001`
- n = 80 official `ac+N` probes
- MAE = 23.972 percentage points
- RMSE = 29.095 percentage points
- Bias = -20.833 percentage points
- R2 = -2.311768
- Pearson = 0.071789

## Diagnostic Findings

- No tested x/y flip, x/y swap, or 90-degree coordinate transform makes official z=2 m R2 positive.
- Identity remains the best Pearson transform at Pearson = 0.071789.
- The best R2 transform is `flip_y`, but R2 remains negative at -2.111059.
- The next accuracy target is therefore near-wall sampling and wall/probe protocol fidelity rather than a simple global coordinate flip.

## Included Software and Audit Changes

  - `z_plus_half_velocity_ratio`

- Updated the Case E validation report to include spatial alignment and probe-mode compile evidence when present.

## Default vs Experimental

Default-safe:

- Build-chain fallback and manifest/audit reporting.
- Fail-closed release gate.
- Solid-corner risk reporting.
- Case A smoke-regression guard.

Preset-only:

- AIJ Case E `ac+N` constants, AF profile scaling, official z=2 m probe target.

Experimental only:

- probe-mode diagnostic runner;
- wind-direction audit (`+Y` vs `-Y`);
- no-SUBGRID diagnostic run;
- sample interval changes for CPU-side probe extraction;
- near-wall, rough-wall, effective-ground, `nu_lbm`, and alternative probe sampling modes.

## Manuscript Use

Paper-ready:

- Dataset provenance, hashes, and official 80-probe z=2 m protocol.
- Current-machine build/runtime evidence.
- Case A smoke regression as a workflow non-regression guard.
- Negative diagnostic finding that simple coordinate transforms do not explain the failed Case E R2.
- Solid-corner diagnostic as a limitation/protocol-risk analysis.

Limitations only:

- Current Case E accuracy metrics.
- Probe-mode runner compile evidence; it is not a solver-result metric.
- Any claim of predictive accuracy, mesh independence, LES improvement, or validated v0.4.0 performance.

## Release Gate

Formal `v0.4.0` must not be tagged until the official z=2 m metric gate passes and Rhino/Grasshopper loads the new GHA. This rc adds better diagnostics, but official Case E accuracy remains below the required threshold.
