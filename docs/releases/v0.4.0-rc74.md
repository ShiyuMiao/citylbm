# CityLBM v0.4.0-rc74

## Scope

This release candidate creates a deterministic lightweight release bundle for
the Case E accuracy-diagnostic line.

## Changed

- Added `casee_release_bundle_gate.py`.
- The gate reads `casee_release_asset_manifest.json`, packages only curated
  lightweight upload assets, and writes a deterministic zip archive with fixed
  internal timestamps.
- The gate verifies each bundled file against the release asset manifest SHA256.
- Raw geometry, VTK outputs, 3dm models, optional logs, and hash-only external
  references remain excluded from the zip.

- Bundle zip:

- Bundled asset count: see the bundle manifest summary.
- Bundle SHA256: see the bundle manifest summary.

## Boundary

This is release-packaging and reproducibility evidence only. It does not create
a GitHub Release, prove Rhino/Grasshopper loaded the plugin in a running
session, run FluidX3D, improve official z=2 m metrics, or permit formal
`v0.4.0`.

Formal `v0.4.0` remains blocked.

Current release-gate official Case E z=2 m metrics remain MAE = 21.111 pp,
R2 = -2.006330, Pearson = 0.115756. The best diagnostic C014 candidate remains
limitations-only with MAE = 13.786 pp, R2 = -0.229845, Pearson = 0.314966.
