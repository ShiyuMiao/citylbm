# CityLBM v0.4.0-rc48

## Scope

`v0.4.0-rc48` feeds the C014 residual-structure diagnosis back into CityLBM as
a default-off residual-target diagnostic hook. It is not a formal `v0.4.0`
release and does not add a new FluidX3D solver run.

## Software Changes

- Added Run Simulation inputs `Diagnostic Residual Target Mode` (`residT`) and
  `Diagnostic Residual Target Scale` (`residS`), defaulting to `none` and `0.0`.
- Added `SimulationSettings` fields for residual-target follow-up metadata.
- Recorded residual-target constants in generated `setup.cpp` without changing
  default solver behavior.
- Extended `citylbm_run_manifest.json` with residual-target mode, scale,
  default-state, solver-default-change, and default-promotion blocker fields.
- Extended default-policy, manifest-schema, manifest-output, and software
  feedback gates to classify residual-target controls as diagnostics only.

## Claim Boundary

Formal `v0.4.0` remains blocked.

Residual-target controls are experimental switches for follow-up planning only.
They do not support predictive accuracy, post-hoc calibration as validation,
mesh independence, LES improvement, default promotion, or a formal `v0.4.0`
tag.
