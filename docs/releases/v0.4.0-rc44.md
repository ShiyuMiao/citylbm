# CityLBM v0.4.0-rc44

## Scope

`v0.4.0-rc44` feeds the C008-C011 AIJ Case E inlet-turbulence finding back into
CityLBM as default-off software capability. It does not add a new formal Case E
metric and is not a formal `v0.4.0` release.

## Software changes

- Added `Run Simulation` inputs:
  - `Diagnostic Inlet Turbulence Mode` (`inletT`), default `none`
  - `Diagnostic Inlet Turbulence Scale` (`inletS`), default `0.0`
- Extended `SimulationSettings` with `DiagnosticInletTurbulenceMode` and
  `DiagnosticInletTurbulenceScale`.
- Extended generated FluidX3D `setup.cpp` output so
  `k_synthetic_fullplane` uses `AF_caseE.csv` z,U,k to create bounded
  full-plane synthetic inlet fluctuations and reapplies the inlet during the
  time loop.
- Extended generated `citylbm_run_manifest.json` with inlet-turbulence
  diagnostic fields and default-promotion blockers.
- Updated default-policy, manifest-output, manifest-schema, and
  software-feedback gates.

## Evidence boundary

The motivating solver evidence remains the completed C008-C011 diagnostic
sweep. The best diagnostic candidate is C011:

- MAE: 14.3750643375 pp
- R2: -0.32680378704255153
- Pearson: 0.2856641275815884

The formal release-gate metric remains the official z=2 m raw-trilinear
baseline:

- MAE: 21.111408125 pp
- R2: -2.006330362229977
- Pearson: 0.11575649438573923

## Claim boundary

`inletT` and `inletS` are experimental switches. They may be used to reproduce
and extend the AF-k inlet-turbulence diagnostics, but they are not default
accuracy settings and cannot support predictive accuracy, mesh independence,
LES improvement, or a formal `v0.4.0` tag while official z=2 m R2 remains
negative.
