# CityLBM v0.4.0-rc80

## Status

This is an accuracy-diagnostic release candidate, not a formal v0.4.0 release.

Formal `v0.4.0` remains blocked because the official AIJ Case E z=2 m gate is still negative: MAE = 21.111 pp, R2 = -2.006330, Pearson = 0.115756.

## Added

- Added default-off native Case E wall/ground follow-up code generation to `generate_native_casee.py`.
- New options:
  - `--wall-model none|voxel_dilation|ground_damping`
  - `--wall-dilation-cells`
  - `--wall-damping-factor`
- Added `casee_wall_followup_codegen_gate.py` to verify the wall/ground options remain default-off, manifest-traced, and blocked from default accuracy promotion.

## Experiment Planning

- Updated the Case E candidate sweep and next experiment runbook so the wall-model follow-up is no longer an implementation placeholder.
- The wall/ground follow-up remains blocked by GPU/runtime and official preflight gates before any long FluidX3D run can be scheduled.

## Boundaries

- This rc does not run FluidX3D.
- This rc does not update official z=2 m metrics.
- This rc does not promote voxel dilation, ground damping, wall roughness, or any diagnostic switch to the default precision model.
- This rc does not support predictive-accuracy, mesh-independence, LES-improvement, or formal `v0.4.0` claims.
