# CityLBM v0.4.0-rc71

## Scope

This release candidate fixes the CityLBM Grasshopper packaging path so all
software-identity gates refer to the same merged GHA artifact.

## Changed

- `CityLBM/build.ps1` now packages the merged `bin/Release/CityLBM.gha`.
- The tracked distributable `CityLBM/bin/CityLBM.gha` is synchronized from the
  merged Release GHA during the build script.
- `build_chain_audit.py` and `citylbm_gha_install_audit.py` now audit
  `CityLBM/bin/Release/CityLBM.gha` as the canonical Release GHA.
- The old nested `bin/Release/CityLBM/CityLBM.gha` copy is now populated from
  the merged Release GHA for compatibility with older manual install notes.
