Release type: accuracy-diagnostic release candidate.

## Manifest Contract Boundary

The schema gate verifies that generated `citylbm_run_manifest.json` files expose the required Case E protocol and claim-boundary fields: official `ac+N` z=2 m raw-trilinear requirements, diagnostic substitute blockers, wall/roughness default-safety fields, probe-protocol risk fields, and paper-forbidden claim classes.

This gate is reviewer-facing traceability evidence. It does not run FluidX3D and does not show an accuracy improvement.
