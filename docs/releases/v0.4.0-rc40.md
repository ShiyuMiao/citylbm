# CityLBM v0.4.0-rc40

## Scope

`v0.4.0-rc40` is an accuracy-diagnostic release candidate for AIJ Case E. It
adds a newly-run C004 dx=3 m low-cost control and integrates the result into
the software-feedback and paper-evidence gates.

This is not a formal `v0.4.0` release.

## Newly-run Case E candidate

- Case: AIJ Case E
- Condition: `ac`
- Wind direction: `N`
- Formal wind vector convention: `(0, -1, 0)`
- Validation height: official z=2 m
- Probe set: 80 official `RS_caseE.csv` probes
- Formal sampling: `raw_trilinear`
- Candidate: C004 dx=3 m low-cost direction/protocol control
- Steps: 48000
- Spinup: 12000
- Source-compile path: audited MinGW/g++ fallback
- Candidate CSV:
  `docs/experiments/casee/results/casee_c004_dx3_low_cost_20260809_214302_probe_time_mean.csv`
- Run log:
  `docs/experiments/casee/results/fluidx3d_c004_dx3_low_cost_run_20260809_214302.log`
- Audit:
  `docs/experiments/casee/results/casee_c004_dx3_low_cost_audit.json`

The C004 run completed 48000 steps and wrote the required official 80-probe
z=2 m CSV. It kept Pearson positive, satisfying its low-cost protocol-regression
condition, but it did not improve the formal metric relative to the current
z-center baseline:

- MAE: 24.48456695 pp
- RMSE: 30.031274078569332 pp
- Bias: -20.695317250000002 pp
- R2: -2.5282993702661267
- Pearson: 0.10934876905648619
- Delta MAE vs z-center baseline: +3.373158825000001 pp
- Delta R2 vs z-center baseline: -0.5219690080361499
- Delta Pearson vs z-center baseline: -0.0064077253292530445

The current best formal official z=2 m result remains the z-center baseline:
MAE 21.111408125 pp, R2 -2.006330362229977, and Pearson
0.11575649438573923.

## Claim boundary

This release candidate supports a low-cost regression claim: the dx=3 m
candidate preserved positive correlation under the official protocol, but it
did not improve accuracy. It does not support predictive accuracy, mesh
independence, LES improvement, a default-parameter promotion, or a formal
`v0.4.0` tag.
