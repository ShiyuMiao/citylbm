## Software Feedback Boundary

The new output points to `citylbm_run_manifest.json`, which records run protocol and claim-boundary metadata. It is useful for paper and reviewer traceability.

The software feedback matrix now includes SF009 for this traceability output. The output is allowed as a default interface feature because it exposes evidence metadata only. It is not a numerical accuracy model, wall model, inlet model, or sampling substitute.

## Not Claimed

This release candidate does not claim:

- AIJ Case E predictive accuracy;
- mesh independence;
- LES improvement;
- field validation for Experiment 3;
- annual comfort or safety compliance;
- Rhino/Grasshopper loading of the newly built GHA;
